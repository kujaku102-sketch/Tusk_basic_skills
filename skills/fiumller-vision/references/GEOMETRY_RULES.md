# UDR幾何候補の解釈

## 1. 座標系体系 (Coordinate Systems)

- **物理DTP座標系 (Page Physical Points)**:
  - 原点 `(0, 0)` は用紙左上。
  - `x` は右方向へ増加（`0.0 .. page_w`）。
  - `y` は下方向へ増加（`0.0 .. page_h`）。
  - A4標準寸法: 幅 `595.28 pt`、高さ `841.89 pt`。

- **FormXObject 内部ローカル座標系**:
  - CADパーツ等の FormXObject は、内部で独立したローカルマトリクス（10分の1縮小など）を持つ場合がある。
  - BBox判定は親マトリクス変換後の物理DTP座標で行う。内部生座標で閾値を判定しない。

## 2. 既定の候補検出

1. **INVALID_RECT**: 数値でないBBox、逆転したBBox。入力構造自体を確認する。
2. **TEXT_OUTSIDE_PAGE**: テキストBBoxが紙面外へ0.5pt以上出る。裁ち落とし等の意図は画像で確認する。
3. **POSSIBLE_TOP_GHOST_RULE**: 上端5pt以内から150pt以降まで伸びる幅2.5pt以下の縦線・パス。正常な罫線の可能性もある。原因は座標だけから断定しない。

## 3. 旧文書向け候補（明示時のみ）

`detect_anomalies.py --legacy-rules`でのみ、右端15pt、図のy=300..378帯、6セル以上の表、7ページ以降のドットリーダーを候補として出す。これらは対象文書のテンプレートを確認しなければ異常判定に使えない。旧ルールの固定条件を他文書へ自動適用しない。

候補がゼロでも画像上の文字欠け、重なり、背景異常が残り得る。FiumLLER画像またはAct3 View画像の視認と、必要に応じたAct4.1 QAを別に行う。
